# Laughlet website

Public pages for the Laughlet iPhone app, served by GitHub Pages at
https://bradenbellinger-cpu.github.io/laughlet/

- `support.html`: support and FAQ (App Store Support URL)
- `privacy.html`: privacy policy (App Store Privacy Policy URL)
- `terms.html`: terms of use

These files are generated from the app's private repo (`website/` + `scripts/build_website.py`).
Edit them there and copy them here, rather than editing them here.
